# Install

## Commands

Clone the repository locally
```bash
git clone https://github.com/elyes-messaadia/my-calculator.git
```

## Features

- **Basic operations**: You can use * / + - operators.
- **Parenthesis**: Unlimited intricated parenthesis operator precedence supported.


## Setup

No setup required.

## Quick Start

1. Run my-calculator:

   ```bash
   py main.py
   ```

2. Type the operation you want to process

3. Hit enter to process the operation

4. Ctrl+C to exit.
